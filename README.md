# improved-bassoon

A simple, responsive calculator built with plain HTML, CSS, and JavaScript. No dependencies or build tools required.

## Run it

Open `index.html` in a modern web browser.

## Features

- Basic arithmetic: addition, subtraction, multiplication, and division
- Decimal input, percentage, sign toggle, and backspace
- Keyboard support: number keys, `+`, `-`, `*`, `/`, `.`, `Enter` (calculate), `Backspace` (delete), and `Escape` (clear)
- Responsive layout and accessible button labels
- Displays an error when dividing by zero
